# 부모 노트 · 이혼 전후 부모 가이드 (PWA)

책 《나는 행복해지기 위해 결혼했다, 이제 행복해지기 위해 이혼한다》의 내용을 상황별로 정리한 웹앱입니다. 설치 후에는 오프라인에서도 열립니다. 서버나 빌드 과정 없이 정적 파일만으로 동작합니다.

## 배포 (GitHub Pages)

1. 새 저장소를 만들고 이 폴더의 파일을 최상위에 그대로 올립니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. `main`에 push하면 자동 배포되고, 주소는 `https://<아이디>.github.io/<저장소명>/` 입니다.
4. 휴대폰 브라우저로 열어 **홈 화면에 추가**합니다.

## 내용을 고칠 때

`index.html` 안의 `const C=` 데이터를 직접 고치거나, 원본 `content.json`을 수정해 다시 빌드하세요.
수정 후에는 `sw.js` 맨 위의 `CACHE` 버전 숫자를 올려야 이미 설치한 기기에 반영됩니다.

## 로컬 확인

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 개인정보

결단문, 점검 체크, 개인 기록은 브라우저 `localStorage`에만 저장되며 어디로도 전송되지 않습니다.
